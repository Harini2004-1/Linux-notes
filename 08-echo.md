## Purpose
The echo command displays text in the terminal. It can also write text into a file using output redirection.

## Syntax
echo "...........any text....."

## Examples
# Display text:
echo "Hello Linux"
# Write text to a file:
echo "Linux is useful" > notes.txt
# Append text to a file:
echo "I am learning Linux" >> notes.txt
# View the file:
cat notes.txt

## Important
> creates a file if it does not exist and replaces its contents if it already exists.
>> appends text to the end of a file.

## Real-Time Use
Useful for creating simple notes, preparing test files, and writing basic command output to files.
