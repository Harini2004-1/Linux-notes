## Purpose:
The rm command removes files. Removed files may not be recoverable through a normal recycle-bin process.

## Syntax:
rm file_name

## Examples:
rm old.txt
# Ask for confirmation before removing a file:
rm -i old.txt
# Remove a directory and its contents:
rm -r old_folder

## Practice:
touch temporary.txt
ls
rm -i temporary.txt

## Real-Time Use
Useful for removing unwanted temporary files and cleaning up test environments.
