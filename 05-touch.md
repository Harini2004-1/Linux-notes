## touch-command

## Purpose:
It is used to create a new file.

## Syntax:
touch file_name

## Example
root@ubuntu:~/Food$ touch Dosa
root@ubuntu:~/Food$ touch Idly
root@ubuntu:~/Food$ ls

Dosa  Idly

## Explanation:
It is used to create a new empty file.

## Key Points:
Used to create a new file.
Helps users create files inside directories.
Can create multiple files at the same time.
Does not add content to the file automatically.
