## cd-command

## Purpose:
The `cd` command changes the current working  directory.

## Syntax:
cd <directory_name>

## Example:
root@ubuntu:~$ mkdir Food
**root@ubuntu:~$ cd Food**
root@ubuntu:~/Food$ 

## Explanation:
`cd` stands for **Change Directory**.
It is used to move from one directory to another directory.

## Key Points:
Changes the current working directory.
Helps users to navigate between directories.
Doesn't create, modify, or delete files.
