## less-command
## Purpose:
The `less` command  displays a file one screen at a time. 
It is useful for reading large files without printing the entire contents at once. 

## Syntax 
   less file_name

## Examples
    less notes.txt
    less /etc/passwd

less /etc/passwd

## Useful Keys
Space — Move forward one page.
b — Move backward one page.
/word — Search for a word.
q — Quit.

## Real-Time Use
Useful for reading large log files and configuration files in Linux.
