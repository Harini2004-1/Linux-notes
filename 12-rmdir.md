## Purpose
The rmdir command removes a directory only when it is empty.

## Syntax:
rmdir directory_name

## Example:
mkdir empty_folder
rmdir empty_folder

## Important:
If the directory contains files or subdirectories, rmdir will fail.

## Practice:
mkdir test_folder
rmdir test_folder
ls

## Real-Time Use:
Useful for cleaning up empty folders without deleting their contents.
