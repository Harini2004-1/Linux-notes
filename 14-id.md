## Purpose:
The id command displays the current user's UID, primary GID, and supplementary groups.

## Syntax:
id

## Examples:
Show information about the current user:
id
Show information about a particular user:
id root
## Possible output:
uid=0(root) gid=0(root) groups=0(root)
## Meaning
uid — User ID.
gid — Primary Group ID.
groups — Groups associated with the user.
The numbers and names depend on the system.

## Real-Time Use
Useful for investigating user permissions and understanding which groups an account belongs to.
