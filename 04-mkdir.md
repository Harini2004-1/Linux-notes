## mkdir-command

# Purpose:
The command creates a new directory.

## Syntax:
mkdir folder_name

## Example
root@ubuntu:~$ mkdir Food

## Explanation:
mkdir stands for **Make Directory**.
It is use to make a new directory.

## Key points:
Used to create a new directory.
Allows users to organize files and folders.
Can create multiple directories at the same time.
Doesn't modify the existing files.
