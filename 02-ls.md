##ls-command

##purpose:
The `ls` command displays the list of file and folder.

##syntax:
ls

##Example:
root@ubuntu:~$ ls
filesystem

##Explanation:
`ls` stands for **List**
It shows the name of all files and folders.

##Key Points:
Displays the list of all files and folders.
Useful for checking the contents of a directory.
Helps users to know what files and folders are available in the current location.
Does not modify or delete any files.
